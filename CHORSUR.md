## What is CHORSUR?

CHORSUR is a custom fork of VS Code, following in the footsteps of Cursor, Windsurf, and Antigravity. It features:

- 🔴 **Devil Theme** — A dark red/black/green color scheme forged in hellfire
- 👹 **Custom Branding** — Demonic cube icon with runic symbols
- ⚡ **All VS Code Features** — Full compatibility with the VS Code ecosystem
- 🌐 **Open VSX Support** — Access to the Open VSX extension registry

## Quick Start

### Prerequisites
- Node.js 20+
- Python 3.x
- Yarn (`npm install -g yarn`)
- Build tools:
  - **Linux**: `sudo apt install build-essential libx11-dev libxkbfile-dev libsecret-1-dev`
  - **macOS**: Xcode Command Line Tools
  - **Windows**: Visual Studio Build Tools

### Build

```bash
git clone https://github.com/bratyabasu07/vscode.git chorsur
cd chorsur
git checkout chorsur-branding
yarn
yarn compile
```

### Run

```bash
# Linux/macOS
./scripts/code.sh

# Windows
.\scripts\code.bat
```
